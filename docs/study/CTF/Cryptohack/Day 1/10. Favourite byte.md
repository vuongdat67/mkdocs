For the next few challenges, you'll use what you've just learned to solve some more XOR puzzles.  
  
I've hidden some data using XOR with a single byte, but that byte is a secret. Don't forget to decode from hex first.  
  ```

73626960647f6b206821204f21254f7d694f7624662065622127234f726927756d
```

## 🔍 Cách giải từng bước

```python
input_str = bytes.fromhex('73626960647f6b206821204f21254f7d694f7624662065622127234f726927756d')

key = input_str[0] ^ ord('c')
print(''.join(chr(c ^ key) for c in input_str))
```

cách khác:
``` python
ciphertext = bytes.fromhex("73626960647f6b206821204f21254f7d694f7624662065622127234f726927756d")
for key in range(256):
    plaintext = bytes([c^key for c in ciphertext])
    try:
        decoded = plaintext.decode()
        if "crypto" in decoded:
            print(f"[+] key:{key}, message:{decoded}")
    except UnicodeDecodeError:
        continue
```
